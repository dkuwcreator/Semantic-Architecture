# Operational Notes (Non-Server)

This repository does **not** ship or support an MCP server runtime.

## What This Repo Provides

- Documentation for the Semantic Architecture framework (see [README.md](README.md) and [docs/](docs/))
- Supporting scripts under [scripts/](scripts/) for semantic validation/reporting

## Run Locally

See [QUICKSTART.md](QUICKSTART.md) for a minimal local setup and a non-server workflow example.

## Run Tests

- Windows: `./run-tests.ps1 all`
- Linux/macOS: `./run-tests.sh all`

If you use Docker for tests, see `docker-compose.test.yml`.

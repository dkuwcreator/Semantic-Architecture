# Spec Kit Workflow Example (NON-NORMATIVE)

This document is **NON-NORMATIVE**.

## Example feature flow

- Write a feature spec in `specs/<feature>/spec.md`.
- Write an implementation plan in `specs/<feature>/plan.md`.
- Write/refresh an ordered task list in `specs/<feature>/tasks.md`.
- Implement tasks phase-by-phase, checking items off as you complete them.

## Notes

- Keep the core model tool-agnostic; do not mention Spec Kit in normative docs.
- Keep adapters optional and clearly labeled.
